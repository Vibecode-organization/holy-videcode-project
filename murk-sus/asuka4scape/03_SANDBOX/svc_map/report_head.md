# Карта Mach/XPC-сервисов, доступных обычному приложению — iOS 27.2 (24B115)

Цель: перечислить всё, что sandbox пускает обычное (не Apple, без приватных энтайтлментов) приложение, привязать каждое имя к бинарю, отметить уже разобранное и выделить непаханое.

## Метод

- Профили: `work/sb272/all.json` (293 SBPL). Разобраны s-выражения парсером с балансировкой скобок (`svc_map/sbparse.py`), извлечены все `(allow mach-lookup ...)` из `container` и `baseline`: 106 правил, 600 уникальных имён.
- Ключевое правило для приложения — `container.sb:13159..13631`: одно `(allow mach-lookup (require-any ...))` с тремя `extension` и плоским списком **463 `global-name` + 48 `xpc-service-name`**. Внутри `require-any` имя — самостоятельная альтернатива, т.е. любое из них приложение может поднять без энтайтлмента. Проверено на практике: `com.apple.mobile.installd` лежит в этом же блоке (стр. 13515) и доступен приложению (см. `installd_nonspi`).
- Ещё 105 правил из 106 — гейтованные или служебные: 60 требуют энтайтлмент, 13 — profile-flag (`common-rules`, `common-mach-lookups`, `common-containermanagerd-rules`, ...), 1 — только `disable-enforcement` (мёртвое), 31 — открытые, но привязанные к подписи/системным атрибутам другого процесса. В основной список они не входят, см. раздел 5.
- Привязка к бинарю: 689 `LaunchDaemons`/`NanoLaunchDaemons`/`DeveloperModeLaunchDaemons` plist'ов вынуты из `141-10327-211.dmg` (`7z x`), распарсены `MachServices` → 2414 имён. Размеры — из `root272_clean_fs.txt`.
- Энтайтлменты: `ldid -e` на 27.2 отдаёт пусто (DER-only блобы), поэтому код-подпись разобрана вручную (`svc_map/ent.py`: LC_CODE_SIGNATURE → SuperBlob → CSSLOT_ENTITLEMENTS), снято с 173 из 174 уникальных бинарей.
- Для 132 имён, не найденных в `LaunchDaemons`, сделан второй проход: извлечены 103 бинаря-кандидата и 57 «сирот» проверены `grep -aF` по FS, плюс сплошной `grep` по 9.1 ГБ dyld shared cache.

Цифры: **463** сервиса в безусловном блоке (+48 xpc-service-name), **331** привязаны к launchd-плисту, **174** уникальных бинаря, **42** правила без хоста в root FS и DSC.

Обозначения в таблице: `ent` — число энтайтлментов у бинаря и маркеры (`mach+N` — список исключений mach-lookup на N имён, `cont` — доступ к контейнерам, `tcc` — приватный TCC, `spi` — private mobileinstall SPI, `fp` — fileprovider). `†` — правило без найденного хоста.
