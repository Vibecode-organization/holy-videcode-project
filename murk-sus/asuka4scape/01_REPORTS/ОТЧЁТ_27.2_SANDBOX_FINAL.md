## 3. SBX IPA — что лежит

`для дипсика 2/08_SBX/`:

| файл | что |
|---|---|
| `SBX_adhoc_full.ipa` | zsign ad-hoc + полные entitlements + `_CodeSignature` |
| `SBX_sym.ipa` | то же + symlink `sbx`/`sbx_abs` + `WorkaroundBundleSymlinkName` |
| `SBX.ipa` | ldid ad-hoc + entitlements (переподписать своим сертификатом) |
| `entitlements.plist`, `ent_min.plist` | наборы entitlements |
| `main.m` | реальные проверки: `csops`, чтение `/private/var/...`, список чужих бандлов, `posix_spawn`, `task_for_pid(launchd)`, `IOSurface sel26`, `container_query(com.apple.Preferences)` |

**Это честный probe, не фейк.** Каждая строка лога — реальный возврат syscall/API.
Если `platform-application`/`task_for_pid-allow`/`iosurfaceinfo` приняты — лог покажет
`OK`; если AMFI режет restricted entitlements — app не установится/не запустится,
и это тоже будет видно (без «1000000 логов»).

## 4. Чего нет и почему

| дверь | гейт | статус |
|---|---|---|
| ad-hoc/self-signed app с `platform-application`, `task_for_pid-allow`, `iosurfaceinfo` | AMFI restricted entitlements; CoreTrust policy | не подтверждено; обычный ad-hoc, скорее всего, reject |
| `installd` install-time symlink/identifier | `com.apple.private.mobileinstall.allowedSPI` на клиенте + `MIFileManager validateSymlinks...` | клиент — Apple-only (Xcode/App Store); SBX_sym — проверка |
| `containermanagerd` чужой контейнер | client identity/audit token + entitlements | SBX container_query — проверка |
| `amfid`/trust cache | `com.apple.private.mis.trust.set`, `amfi.can-load-trust-cache` | Apple-only |
| kernel R/W | SPTM TTBAT closed, IOSurface race fixed, `task_set_special_port` check | у дипсика 1 primitive нет; FUZZ UC 200k чисто |
| CoreTrust local policy (`FUN_94c2bd8`, non-pinned root) | policy flag из AMFI; профиль/цепочка | не подтверждено на устройстве |

**Полного sandbox escape нет.** Причина не в «не искали»: на 27.2 закрыты
SPTM TTBAT, IOSurface-гонка, `task_set_special_port`; restricted entitlements
режет AMFI; `installd`-клиент — Apple-only. Живые лиды — новый app replacement в
`installd` 27.2, `sharingd`/AirDrop, SpringBoard/ImageIO icon path, dsc ObjC fixups
для `InstalledContentLibrary`/`ContainerManagerCommon`.
