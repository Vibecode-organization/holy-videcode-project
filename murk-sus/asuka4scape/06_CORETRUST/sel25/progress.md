- Прочитан `work/agx_iogpu/REPORT.md` §3.1, взяты адреса `0x9947de4` (sel 25), `0x9976cf8` (worker), `0x997700c`.
- Полный дизасм sel 25 + ручной decode ключевых слов (`ldp` @`0x9947ec8`, `umulh` @`0x9947ecc`, `mul` @`0x9947f10`, `cmp` @`0x9947f38`, `mov x2/x3` @`0x9947f50/f54`).
- Установлено: `scalar[2]` = count, `scalar[3]` = stride; worker `x21=x3` (stride), `x22=x2` (count). В отчёте X2 роли перепутаны.
- Найдена вторая ошибка X2: `[accel+0x268]` = 0x30 — это значение **базового** `IOGPUAccelerator::init` (`0x997149c`). AGXG14P перекрывает: `0x8174ec8` (`w8=0x40`), рядом `[+0x278]=0x410` (`0x8174ed0`).
- Проверка согласованности: AGX submit `0x818eb40` читает `[rec+0x30]`/`[rec+0x38]` → запись 0x40 Б; все чтения sel 25 ≤ `+0x3f`. OOB нет.
- Разобран id-путь: `0x9965b58`→`0x9945040`→`0x9944fb8` (bounds + refcount под локом ns+0x20); слот 16 `0x819a468` → база `0x997a40c` (`q->[0x580]=obj`) + `isKindOf AGXDebugBufferShmem` → `[obj+0x68]=0`; `q+0x580` только release в конце итерации.
- Выход: `scalarOutput[0] = [q+0x520]` (статус). Валидность id не наблюдается → оракула нет.
- Проверены соседние 6/8/26/27/38/39/45: чтения в пределах объявленного размера.
- Итог: дефекта нет, примитива нет. Отчёт: `work/sel25/REPORT.md`; запись в `CHAT_дипсики.md`.
