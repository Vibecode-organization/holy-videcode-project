# Дифф SPTM: 27.0.1 (T8110, SPTM-820.0.22) → 27.2 RC 24B115 (SPTM-820.40.24) — +0x11B8 кода, фикс TLB-гонки, IOMMU read-refcount, hibernation-hardening, DART clock protection

**Кратко:** Побайтово сравнил два T8110-бинаря SPTM из архива: 02_KERNEL/sptm/27.0.1/sptm_27.0.1_t8110.macho (1 196 064 B, SPTM-820.0.22, сборка 2026-08-08) и 02_KERNEL/sptm/27.2/sptm.macho (1 212 448 B, SPTM-820.40.24, 2026-10-03). Дельта: __TEXT_EXEC +0x4000 (из них __text +0x11B8, 4536 B), __cstring +0x4D4, __DATA_CONST __const +0x10. Строковый дифф: +32 новые, -7 удалённых. Новое — ровно протокол фикса TLB-гонки из 27.2b3: uat_sync_outer_tlb_sapt_flush, uat_dekkerlock_lock, uat_dekker_gate_lock, таймауты «UAT Dekker {lock,gate} acquisition timed out», verify-gmmu-tlbis-at-sync + gmmu-tlbi-verification-reg/bit, «Failed to verify TLBI», «The GMMU TLBI verification register should be 8B-aligned», VIOLATION_T8110_DART_UNGANG_GAPF_RACE, отказ relaxed_rw_protections+allow_pte_remap, DART «Inconsistent unganged clock protection configuration». Сверх публичного b3-диффа у нашей сборки есть ещё три блока: (1) IOMMU read-refcount — новое сообщение fte/new_type/page_flags/read_refcnt/iommu_read_refcnt и проверка «iommu_read_refcnt > read_refcnt»; (2) hibernation-hardening — VIOLATION_NVME_ILLEGAL_HIBERNATION_QUEUE_LATCH, enforce_no_hib_latch, /chosen/manifest-properties, лимит hib_header_copy->handoffPageCount; (3) SPTM internal-use-only unit — sptm_is_iuou_or_iuos_device, sptm_allow_vm_isa_internal_guests, sptm_t8110dart_skip_disable_clock_protection_write. Удалена строка «wrprot» (как и в публичном b3-диффе). Адреса xref'ов нового кода зафиксированы, чтобы следующий исследователь не искал заново.

### 4. Качественная оценка кода
Из 242 функций (границы по `bti c`) 156 имеют идентичный нормализованный хэш
(с вырезанными adrp/branch-иммедиатами), т.е. ~64 % кода не менялись; остальное —
перекомпоновка + вставки. Точную пофункциональную пару «было→стало» без символьной
таблицы (SPTM stripped) не строил: адреса сдвинуты, часть функций переставлена.

Версии подтверждены строками внутри самих бинарей.

## Impact
- 27.2 RC = 27.0.1 + полный b3-протокол TLB-фикса (гейт, флаш, верификация) — это независимое
  подтверждение вывода отчёта id 10 уже на уровне диффа, а не одной декомпиляции.
- Дополнительно к публичному b3-набору в нашей сборке появились:
  **IOMMU read-refcount** (разделение read/IOMMU-refcount для FTE),
  **hibernation hardening** (запрет latch в NVMe-очереди, лимит handoff-страниц),
  **DART clock protection** и **IUO-проверки** (internal-use-only).
- Значит публичная карта «что нового в 27.2b3» неполна для T8110: как минимум три блока
  добавлены позже/отдельно, и именно они — свежая поверхность (hib-путь и IOMMU-refcount).

## Next step
