# OpenWrt Studio Mobile / Linux

Приложение управления OpenWrt для Android и Linux. Форк cogwheel0/luci-mobile.

- Автор/сопровождение: [RichkovGit](https://github.com/RichkovGit).
- Версия: **v2.5.27-mobile**.
- Платформы: Android, Linux x86_64.
- [Исходники и полная инструкция](https://github.com/RichkovGit/OpenWrtStudio-Mobile).
- [Оригинальный релиз](https://github.com/RichkovGit/OpenWrtStudio-Mobile/releases/tag/v2.5.27-mobile).
- [Скачать единый архив OpenWrtStudio-Mobile_RichkovGit.zip](https://github.com/murk-sus/holy-videcode-project/releases/download/RichkovGit/openwrtstudio-mobile/OpenWrtStudio-Mobile_RichkovGit.zip).

## Установка

Android: установите APK для своей архитектуры (обычно arm64-v8a). AAB предназначен для распространения, не для прямой установки. Linux: следуйте LINUX_INSTALL.md; требуется glibc 2.35+.

Бинарные файлы взяты из указанного опубликованного релиза без изменений; подписи APK сохранены. В архиве есть README.txt с версией, инструкцией и ссылками. Лицензии и сведения об исходных авторах доступны в исходном репозитории. APK в проекте LuCI не являются приложениями Android.
