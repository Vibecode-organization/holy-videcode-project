## Установка

OpenWrt 24.10 с ucode LuCI: установите оба IPK через opkg. OpenWrt 25.12: установите оба APK через apk add --allow-untrusted. Эти APK предназначены для OpenWrt, не для Android. Сначала сделайте резервную копию. Тема выбирается вручную в Система → Система → Язык и оформление. Полная инструкция в исходном репозитории.

Бинарные файлы взяты из указанного опубликованного релиза без изменений; подписи APK сохранены. В архиве есть README.txt с версией, инструкцией и ссылками. Лицензии и сведения об исходных авторах доступны в исходном репозитории. APK в проекте LuCI не являются приложениями Android.
