# Flow Studio

Независимый клиент Google Flow: облачная медиатека, генерация видео и локальный монтаж. Не является продуктом Google.

- Автор/сопровождение: [RichkovGit](https://github.com/RichkovGit).
- Версия: **v2.0.1**.
- Платформы: Windows x64.
- [Исходники и полная инструкция](https://github.com/RichkovGit/GoogleFlowDesktop).
- [Оригинальный релиз](https://github.com/RichkovGit/GoogleFlowDesktop/releases/tag/v2.0.1).
- [Скачать единый архив GoogleFlowDesktop_RichkovGit.zip](https://github.com/murk-sus/holy-videcode-project/releases/download/RichkovGit/googleflowdesktop/GoogleFlowDesktop_RichkovGit.zip).

## Установка

Распакуйте Windows/FlowStudio-2.0.1-win-x64.zip целиком в доступную для записи папку и запустите FlowStudio.exe. Нужен аккаунт Google Flow; генерация может расходовать кредиты аккаунта. Поддерживаемые операции и ограничения описаны в исходном README.

Бинарные файлы взяты из указанного опубликованного релиза без изменений; подписи APK сохранены. В архиве есть README.txt с версией, инструкцией и ссылками. Лицензии и сведения об исходных авторах доступны в исходном репозитории. APK в проекте LuCI не являются приложениями Android.
