# support/

Реквизиты участников для вкладки «Поддержка» на сайте.
Каждый файл `<github-логин>.json` создаётся и изменяется через сайт после входа через GitHub.
Руками эти файлы лучше не трогать.

Payment details shown on the site's "Support" tab. Each `<github-login>.json` file is created and edited through the site after signing in with GitHub. Please don't edit these files by hand.
