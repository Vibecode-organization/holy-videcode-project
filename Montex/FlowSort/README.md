# FlowSort

Минималистичный органайзер файлов для Windows с интерфейсом в стиле **Obsidian Liquid Glass** и интерактивным **3D Tilt** эффектом. Автоматически раскладывает файлы по категориям в один клик или в фоновом режиме.

## Возможности

* **Мгновенная и фоновая сортировка:** ручной запуск кнопкой **Sort Now** или непрерывное отслеживание новых файлов каждые 2 секунды (**Auto-sort**).
* **Безопасное переименование:** при совпадении имён файлов дубликаты не перезаписываются, а получают индекс `file (1).ext`.
* **Нативный выбор папки:** встроенный системный диалог выбора директории (**Browse**) и ручной ввод пути.
* **Автономность (Single-File):** не требует установки .NET Runtime или дополнительных библиотек — всё упаковано в один исполняемый файл `FlowSort.exe`.

## Категории сортировки

| Папка | Расширения файлов |
| :--- | :--- |
| **Images** | `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.svg`, `.heic` |
| **Documents** | `.pdf`, `.doc`, `.docx`, `.xls`, `.xlsx`, `.txt`, `.pptx` |
| **Archives** | `.zip`, `.rar`, `.7z`, `.tar`, `.gz` |
| **Installers** | `.exe`, `.msi`, `.iso`, `.dmg` |
| **Video** | `.mp4`, `.mkv`, `.avi`, `.mov`, `.webm` |
| **Audio** | `.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a` |
| **Torrents** | `.torrent` |
| **Other** | Все остальные форматы (временные файлы `.tmp`, `.crdownload`, `.part` игнорируются) |

## Быстрый старт

1. Скачайте **`FlowSort.exe`** из раздела релизов (или папки сборки).
2. Запустите файл двойным кликом — локальный сервер автоматически откроет интерфейс в браузере по адресу `http://localhost:5055/`.
3. Выберите целевую папку (по умолчанию выбрана папка `Downloads`) и нажмите **Sort Now** или активируйте **Auto-sort**.
