# ✨ Stars

**Версия:** v1.0  
**Платформы:** Android, Windows, macOS, Linux, любой современный браузер

**Описание:** Притяни частицы пальцем — они соберутся вокруг. Отпусти — разлетятся в стороны. Управляй частицами одним касанием.

---

## 🎮 Как играть

1. **Коснись экрана** — частицы начнут стягиваться к пальцу, образуя плотное скопление.
2. **Веди палец** — созвездие следует за тобой, увлекая всё новые частицы.
3. **Отпусти** — частицы с силой разлетаются в разные стороны, постепенно замедляясь и снова наполняя экран.

Никаких правил и целей — просто управляй гравитацией одним касанием.
