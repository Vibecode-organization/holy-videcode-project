# Neon Stars
Версия: v1.0.
Платформа: Windows.
Описание: Neon Stars — интерактивная «песочница» с неоновыми частицами.
Язык программирования: C.

# Управление
| Действие | Клавиша / кнопка |

| Притягивать звёзды | Движение мыши |
| Разброс звёзд | ЛКМ |
| Добавить 20 звёзд | Пробел |
| Выход | Esc |

# Сборка 
## MinGW (gcc)
gcc neon_stars.c -o neon_stars.exe -lgdi32 -luser32 -lwinmm -lm -mwindows

# Требования
- Windows 7 или новее.
- Компилятор C11: MinGW-w64, MSVC 2019+, Clang.
- Сторонние библиотеки не нужны — только системные `user32`, `gdi32`, `winmm`.

# Настройка
Все ключевые параметры вынесены в `#define` в начале файла.
| Параметр | По умолчанию | Что делает |

| `MAX_STARS` | `8000` | Общий размер массива звёзд |
| `MAX_ALIVE` | `3000` | Мягкий лимит живых звёзд |
| `START_STARS` | `600` | Сколько звёзд на старте |
| `SPAWN_INTERVAL` | `40` мс | Интервал автоспавна |
| `SPACE_BURST` | `20` | Звёзд за одно нажатие пробела |
| `ATTRACT_RADIUS` | `120.0f` | Радиус притяжения |
| `ATTRACT_FORCE` | `0.30f` | Сила притяжения |
| `STICK_DIST` | `4.0f` | Порог прилипания |
| `PHYS_DAMPING` | `0.965f` | Трение |
| `STICK_LERP` | `0.22f` | Плавность подтягивания |
| `BOUND_BOUNCE` | `0.85f` | Упругость отскока |
| `WIN_W`, `WIN_H` | `640×480` | Стартовый размер окна |

## Производительность
FPS не ограничен — цикл крутится настолько быстро, насколько позволяет железо.
