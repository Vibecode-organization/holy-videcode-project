Здесь участники репозитория публикуют свои реквизиты. Каждый может добавить и изменить только свои — сайт проверяет ник через GitHub.

Вход через GitHub

Сайт работает без сервера, поэтому для входа нужен личный токен GitHub. Он хранится только в этой вкладке браузера и отправляется только на api.github.com.

  1. Откройте создание токена (тип classic, галочка public_repo уже стоит).
  2. Нажмите Generate token и скопируйте его.
  3. Вставьте токен ниже.

Вы редактируете только свои реквизиты
Способы оплаты Все поля по желанию

Репозиторий публичный: всё, что вы укажете, увидят все. Не добавляйте то, что не хотите показывать.
